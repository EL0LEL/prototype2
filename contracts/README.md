# Kontrak antarbagian

Folder ini menjadi acuan bersama sebelum frontend, backend, AI Engineering, dan Data Science menghubungkan pekerjaan.

- [api](api/README.md): request, response, hak akses, dan kegagalan layanan.
- [data](data/README.md): skema katalog, pesanan, dataset, dan artefak analisis.
- [examples](examples/README.md): contoh kecil yang aman dan sesuai kontrak.

Kontrak dimiliki bersama oleh pihak yang mengirim dan menerima data. Jangan mengganti nama field, tipe, satuan, endpoint, atau perilaku error diam-diam.

Commit ini menetapkan tempat dan proses pengelolaan kontrak. Belum ada OpenAPI atau JSON Schema final. Kontrak yang belum disepakati harus diberi status draf, bukan dianggap API yang sudah berjalan.
