# Contoh untuk integrasi

Belum ada contoh data yang ditambahkan.

Gunakan area ini untuk fixture kecil yang disamarkan atau dibuat khusus untuk pengujian. Beri label bahwa data itu contoh, tulis sumber/cara pembuatannya, dan hubungkan ke versi kontrak yang sesuai.

Jangan menyebut contoh sebagai katalog resmi, transaksi nyata, hasil model terlatih, atau hasil evaluasi usaha. Jangan menyalin data pelanggan, token, log provider yang memuat secret, atau dataset besar.

Pihak penerima harus dapat menjelaskan apa yang diuji oleh setiap contoh. Data kerja yang belum ditinjau tetap berada di lokasi lokal DS.
