# Notebook

Gunakan notebook untuk eksplorasi, pemeriksaan data, dan penjelasan eksperimen. Belum ada notebook atau hasil eksperimen pada commit awal.

Beri nama yang menjelaskan urutan dan tujuannya, misalnya `01_catalog_quality.ipynb` ketika pemeriksaan katalog benar-benar mulai dikerjakan.

Sebelum commit, periksa kode, output, metadata, dan attachment. Pastikan tidak ada secret, alamat lokal pribadi, tabel pelanggan, atau klaim hasil yang tidak berasal dari run nyata.

Transformasi yang dipakai frontend, backend, atau layanan model harus dipindahkan ke modul yang dapat diuji. Notebook tidak menjadi dependensi runtime aplikasi.
